# Tarumi v1.4.8

Welcome to Tarumi v1.4.8! This update focuses on cleaning up the layout, optimizing source management, updating card styles, and restoring stable typography across the application.

## Key Changes & Enhancements

### 1. Dynamic Source Catalog Filtering
* **Improved Discovery Flow**: The source catalog now dynamically displays only disabled (unadded) sources by default.
* **Instant Addition & Removal**: Tapping the `+` icon on any source instantly adds it to your active source list and dynamically removes it from the catalog, preventing redundant listings.

### 2. Refined Homepage Top App Bar
* **Branding Layout**: Redesigned the top brand header featuring the Tarumi mascot avatar alongside bold typography ("TARUMI / COMICS READER") with a wider letter-spacing configuration.
* **Clean Interface**: Removed the history shortcut icon from the top app bar to declutter the header area and optimize screen space.

### 3. Hitomi.la Catalog Search & Filters
* **Multi-Filter Support**: Expanded filtering support to handle locale mapping and content types (Doujinshi, Manga, Artist CG, Game CG, etc.) seamlessly.
* **Advanced Query Construction**: Combined selected tags, queries, and content types into a unified query stream.

### 4. Custom Outlined Cards & Global Theming
* **Corner Radius Overlay**: Outlined material card views across the app have been upgraded to a premium `16dp` corner radius.
* **Adaptive Color Borders**: Configured borders and surfaces to dynamically map to the theme outline and surface container low colors, ensuring absolute harmony with light, dark, and coffee theme modes.

### 5. Home Screen & Trending Settings
* **Layout Scaling**: Adjusted trending cover card titles from `14sp` to `12sp` for a cleaner grid view.
* **Updated Headers**: Renamed the home feed's trending category header to "Trending Today".

### 6. Typography & System Alignments
* **Font Restorations**: Restored standard stable sans-serif typography across bottom navigation elements, Ask AI chat bubbles, and reading statistic period tabs.
